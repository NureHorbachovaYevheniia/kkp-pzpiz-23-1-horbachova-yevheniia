# IoT-симулятор Learnly

Програмна реалізація концепції розумного навчального пристрою.
Пристрій підключається до серверної частини через REST API.

## Запуск

1. Запустіть сервер:
   ```
   cd server
   npm start
   ```

2. Відкрийте в браузері:
   ```
   http://localhost:3001/iot/
   ```

## Демо-акаунт учня

## Як користуватись

1. Увійти як учень
2. Натиснути «Навчання»
3. Обрати набір слів
4. Переглянути слово → «Переклад»
5. «Знаю» або «Повторити» — прогрес зберігається на сервері

## Файли

- `index.html` — розмітка пристрою
- `style.css` — стилі OLED-екрану
- `app.js` — логіка та запити до API

## API, які використовує пристрій

- `POST /api/auth/login` — вхід
- `GET /api/my-sets` — список наборів
- `GET /api/my-sets/:id/study` — картки для навчання
- `POST /api/my-sets/:id/progress` — збереження прогресу
